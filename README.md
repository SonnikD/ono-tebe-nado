# Оно тебе надо — аукцион

Вёрстка лендинга аукциона по готовому макету на HTML и CSS, без сборщиков и зависимостей.

## Макет

[Ссылка](https://www.figma.com/file/8KwhMpv8qnDocX4NVFQBpn/Оно-тебе-надо?type=design&node-id=0-1&mode=design&t=qag0ANet3vliwuDo-0)

## Технологии

- HTML5: семантические элементы
- CSS3: Flexbox, Grid, позиционирование, кастомные свойства
- БЭМ
- Локальный шрифт через `@font-face`

## Структура

```
ono-tebe-nado/
├── index.html
├── fonts/
├── images/
└── styles/
    ├── global.css      # сброс браузерных стилей
    └── style.css       # основные стили
```

## Запуск

Открыть `index.html` в браузере — сборка не требуется.
